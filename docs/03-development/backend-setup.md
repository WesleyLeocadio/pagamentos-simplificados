# Configuração do Backend

1. Instale Java 21 e Docker.
2. Configure o PostgreSQL local ou via Docker.
3. Clone o repositório e rode:
   ```sh
   ./mvnw spring-boot:run
   ```
4. Acesse a documentação Swagger em `/swagger-ui.html`.

Veja detalhes de endpoints no [PRD](../../src/main/java/com/github/wesleyLeocadio/pagamentos_simplificados/prd.md).
