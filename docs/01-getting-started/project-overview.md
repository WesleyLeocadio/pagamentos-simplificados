# Visão Geral do Projeto

O **pagamentos-simplificados** tem como objetivo principal o estudo de arquitetura, testes, boas práticas e integração com serviços externos, simulando transferências financeiras entre usuários.

## Objetivos
- Cadastro de usuários (comum e lojista)
- Transferência de valores entre usuários
- Validação de saldo
- Integração com serviços externos de autorização e notificação

Veja detalhes no [PRD](../../src/main/java/com/github/wesleyLeocadio/pagamentos_simplificados/prd.md).
